# モンゴル「介護サービスに関する法律」案とパーソナルアシスタンス

**分析メモ** · RELAVIN · 2026年8月27日
**評価対象**: 「介護サービスに関する法律」案（Асрах үйлчилгээний тухай хууль、2026年6月22日国会提出）を、**2016年障害者権利法32条**および**労働社会保障大臣命令 A/187（2021年）**と併せて読む
**評価道具**: 国連人権高等弁務官事務所『障害者のためのケア・支援システム — 国レベル評価ツール』（ACNUDH, 2026, HR/PUB/25/3）13指標

> **結論を先に**: モンゴルは、パーソナルアシスタンス（AP）について**ラテンアメリカのどの国よりも整った規範体系を既に持っている**——一次法にAPの権利、施行規程、AP専用の基準、2つの法定財源。にもかかわらずAPは規模を持たず、実績データも公表されていない。そして現在、それを**引き下げる方向に作用しうる立法**が国会で進んでいる。

> **参照した法案テキストについて**: 手元にある日本語訳は2026年1月21日付・13章50条の作業稿。2026年6月22日に国会へ提出された版は報道によれば10章30条。以下の条文番号は作業稿に基づくため、**提出版の正文で振り直す必要がある**。ただし構造（サービス3類型・提供4形態・調達型財源）は提出版の報道要約と一致しており、本メモの分析上の結論は変わらない。

## 1. 法案の性格 — 介助者制度ではなく、介護サービス産業の許認可法

### 1.1 立法の建て付け

2026年6月22日、D. Энхтуяа／А. Ганбаатар 両議員ほか計64名が共同提出。7月3日の本会議で審議入りが承認され、春会期は閉会した。提出理由は「介護サービスの規定が社会福祉法ほかに散在しており、包括的な法的枠組みがない」こと。

- **対象**（3.2）: 高齢者・障害者・複合的支援を要する者・**妊産婦と新生児**を一括
- **サービス3類型**（6条）: ①日常生活介護支援 ②リハビリテーション介護 ③人権・社会参加支援
- **提供4形態**（7条）: 自宅／入所／巡回・移動／デイケア
- **提供主体**（13条・14条）: 許可を受けた「サービス提供機関」「代替型介護サービスセンター」。建物・設備基準あり
- **人材**（31条・32条）: 「介護専門職員」——承認研修修了＋**資格証取得が必須**（31.2、32.2）
- **財源**（37条・38条）: 国は**センターからサービスを調達**する（38.1）。ほかに利用者負担（39条）・任意保険（40条）

### 1.2 CDPD第19条の観点から見た4つの欠落

| 論点 | 法案の建て付け | 帰結 |
|---|---|---|
| **雇用主は誰か** | 供給は許可を受けた機関単位（13条）。本人が介助者を選任・指示する類型がない | 本人が雇用主になれない |
| **誰が介助者になれるか** | 承認研修＋資格証必須（31.2、32.2）。例外規定なし | 本人が選んだ人は法的に介助者になれない |
| **金は誰に渡るか** | 国→センターへの調達（38.1）。財源の源泉（37条）に個別給付がない | 個人予算が構造的に存在しない |
| **本人の権利は何か** | 「サービスの種類・形態・**提供機関を自由に選択する権利**」（10.1.1） | choice of provider どまり。control ではない |

さらに二点。**「自立」の語義がリハビリ的である**——6.2は「日常生活動作を自立して行える能力を高めること」を目的とする。ADL自立度の向上であって、CDPD 19条の autonomy（自分で決める）ではない。そして**代理決定が法文に埋め込まれている**——4.1.4は要介護者の定義に「本人**若しくはその法定代理人**が介護サービスを申請した者」を含める。

法案全体に「パーソナルアシスタンス（хувийн туслах）」の語は**一度も現れない**。

### 1.3 法案が持っている良い部分

- **6.4「人権及び社会参加介護支援」を独立の類型として立てた**こと。名誉・権利・財産の保護、社会関係・文化・情報アクセス・参加の確保、暴力の予防と被害救済——自立生活の理念を注入できる器になる
- **36.2「介護サービスの財源は社会福祉手当と同一視されず、サービスの実際の費用及び質に基づく」**。手当モデルからサービスモデルへの転換宣言であり、AP財源論の前提としては正しい
- **7.8**「国が提供するサービス、民間からの調達費用、割引、保険基金の財源に関する手続は**政府が定める**」＝法改正なしで動かせる下位規範の入口
- **34.3** 研修カリキュラム策定にあたり「**国際的な優良事例を考慮する**」——外国の介助者養成研修を持ち込む明文の根拠になりうる

## 2. なぜ今この法律が出てくるのか

### 2.1 「アジアの中で社会保障が充実している」の中身

モンゴルの社会福祉支出は**GDP比2.12%（2018年）**で、東アジア・大洋州地域平均の約1%、低中所得国平均1.4%を大きく上回る（世界銀行）。この評価は正しく、しかも近年さらに厚くなっている。

労働社会保障大臣の国会報告（2023年11月3日）によれば、障害年金は月**325,000トゥグルグ**（2018年の188,000から増額）、常時介護を要する者の**介護者**への手当は月**275,000トゥグルグ**（同84,000から増額）。5年で3倍以上である。障害者は115,100人（うち子ども11,800人）、就労年齢約90,000人に対し就労は約13,000人。

2016年障害者権利法26条が列挙する給付も細かい——暖房・光熱費補助、義肢装具（3年ごと100%償還）、車いす、通信費補助、点字郵便、療養所への交通・宿泊補助、幼稚園給食費、水治療法70%償還。同32.8は公共交通の無料利用を保障する。**ラテンアメリカの多くの国より整備されている、というのは事実である。**

**しかし増額されたのは「介護者への手当」であって、本人が介助を購入する財源ではない。** 月275,000トゥグルグ（約US$80相当）は家族介護者への報奨としては増えたが、介助サービスの対価としては成立しない。2018年のJICA DPUBニュースレター第7号がメインストリーム協会の訪問に対して述べた指摘——「社会保障制度が整備されているといっても、年金や手当の額は少なく、**介助者費用を賄えるものでない**」——は、金額が3倍になった今も構造として残っている。

その結果、**障害者にとっての主要サービスは今も入所施設（asramjiin gazar）である。**

### 2.2 立法を押している4つの力

1. **高齢化とADBの長期ケア議題**。65歳以上人口は5.43%（2025年）とまだ低いが増加局面。ADBは2020年に『Country Diagnostic Study on Long-Term Care in Mongolia』を出し、以後 TA 56211-001「Developing Elderly Care System and Services in Mongolia」で高齢者ケア制度整備を支援している。**今回の法案は基本的にこの高齢者ケアの系譜から来ており、障害者はそこに追加された**
2. **2024年の高齢者法改正**。アセスメントとケースマネジメントを導入し、在宅サービス予算を約20倍に増額。在宅への舵は既に切られている
3. **規定の散在**。統合立法の需要は実在する（提出者の説明）
4. **CDPD第2・3回審査（2023年8月、CRPD/C/MNG/CO/2-3）**。委員会は民法の後見・代替決定制度の廃止に進展がないことを重ねて指摘し、**期限・指標・財源を伴う全国的な脱施設化戦略**と、**既存・新規の施設へのこれ以上の投資を行わないこと**を求めた。同時に前回勧告の大半が未実施であることを確認している

### 2.3 本質的な矛盾

**CRPD委員会が「施設に今後一切投資するな」と勧告した3年後に、モンゴル国会は「代替型介護サービスセンター」を許認可・基準・国庫調達つきで制度化する法案を審議している。**

法案43条は移行措置を、44条は「現行の介護提供者に関する調整」を置く。つまりこの法律は**既存の施設ストックを合法化し、財政的に安定させ、産業として育てる**方向に作用する。7.5は入所サービスを、14条は施設の建物基準を、25条はインフラ・投資支援を定めている。

## 3. モンゴルが既に持っているもの — 32条と大臣命令 A/187

**ここが本メモの中心である。** 一般に「モンゴルには介助制度がない」と理解されているが、規範上はそうではない。

### 3.1 2016年障害者権利法 第32条（原文と訳）

> **32.1** Хөгжлийн бэрхшээлтэй хүн бие даан амьдрах эрхтэй.
> **32.2** **Хувийн туслах үйлчилгээ**, зөвлөлдөх бүлэг буюу харилцан суралцах, зөвлөгөө өгөх үйлчилгээгээр хөгжлийн бэрхшээлтэй хүний бие даан амьдрах эрх нь хангагдана.

- **32.1** 障害者は自立して生活する権利を有する
- **32.2** 障害者の自立生活の権利は、**パーソナルアシスタンス・サービス**、ピアグループ（相互学習）および相談サービスによって確保される
- **32.3** 自立生活支援サービスの手続・種類・形態、提供機関に対する要件は、障害者問題担当の政府構成員が定める
- **32.4** 個人および法人が自立生活支援サービスを提供できる
- **32.5** 提供機関の選定は、首都・県の福祉担当行政機関が行う
- **32.6** 32.2〜32.5の実施にあたっては、**障害者の権利擁護を任務とするNGOの参画を確保する**

32.2はCILの三本柱（介助・ピアサポート・相談）をそのまま一次法に書き込んでいる。**チリのLey 21.805にもメキシコ市のケアシステム法にも存在しない到達点である。**

### 3.2 大臣命令 A/187（2021年11月25日、2022年7月1日施行）

32.3が命じた規程は**策定済み**である。労働社会保障大臣命令 A/187 が、以下の3つを一括で承認している。

1. 障害者の自立生活支援サービスに関する規程
2. **パーソナルアシスタンス・サービスに求められる基準**（Хувийн туслах үйлчилгээнд тавигдах шалгуур）
3. ピアグループ／相談サービスに関する基準

しかもこれは「шинэчлэн батлах（**改訂**承認）」であり、それ以前の版が存在した。2017年3月には規程案がパブリックコメントに付されている。**モンゴルは法制定の翌年から下位規範の整備に着手していた。**

### 3.3 AP基準の中身 — どこまで行っていて、どこで止まっているか

**到達している点：**

- **介助の業務範囲が広く、正しい**。社会参加（地域活動、買い物、銀行、医療機関、就労支援）／情報アクセス（代読、手話通訳）／家事・身体介護（外出、調理・食事、入浴、洗濯、整容、体位変換、清掃）。**買い物や銀行や就労が入っている**——これは介護ではなく介助の業務定義である
- **提供主体が開かれている**。個人・企業・NGOのいずれもが提供できる（32.4）
- **財源が2経路、法定されている**。**社会福祉基金**および**雇用支援基金**。APを雇用支援の財源で賄う設計は国際的にも珍しく、示唆に富む
- **介助者要件が軽い**。研修受講と能力形成、障害に関する一般的知識、応急手当と介助の経験、障害種別に応じたコミュニケーション（手話を含む）、年1回の健康診断。**資格証は要求されていない**
- **DPOの参画が法律上の義務**（32.6）
- **本人の同意による選択**。定められたサービス類型の中から本人と「合意」して決める

**止まっている点：**

| 論点 | 現状 |
|---|---|
| 雇用主 | 介助者は**提供機関の被用者**（常勤または臨時）。本人と個人の雇用関係を結ぶ枠組みではない |
| 個別性 | **1人の介助者が複数の利用者を担当しうる**。1日8時間まで |
| 時間数 | 支給時間数の基準が公示されていない |
| 単価・報酬 | AP基準に金額の定めがなく、単価表も公表されていない |
| 受給資格 | 本人側の受給要件・ニーズ評価の手続が基準上明確でない |
| 家族介助 | 家族が介助者になれるかの定めがない |
| 実績データ | **全国で何人がAPを利用しているかの公表統計が見当たらない** |

### 3.4 したがって、問題設定が変わる

規範の欠如ではない。**規範はあるが、金額・時間数・受給手続という「動かすための数字」が空白のまま5年が経ち、規模を持たなかった。** そして本人が雇用主になる回路が最初から設計に入っていない。

そこへ介護サービス法案が来る。法案が現在の形で成立すると：

- APを担う者は「介護専門職員」として**資格証**を求められうる（法案31.2、32.2）— A/187の軽い要件が上書きされる
- 財源は**許可を受けたセンターからの国庫調達**に一本化されうる（法案38.1）— 社会福祉基金・雇用支援基金からのAP財源の位置づけが不明確になる
- 法案は32条にもA/187にも**相互参照を置いていない**

**モンゴルは、規範上ラテンアメリカのどの国よりAPが整っている。そして今、それを下げる方向の立法が進んでいる。** これが本件の核心である。

### 4.2 総合評価：**約40–45%**（1.2.3 単独では 45–50%）

**プロフィールが特異である。** 古典的な障害給付・アクセシビリティ指標（1.1.4／1.1.5／1.3.5）は域内上位に匹敵し、**人的支援（1.2.3）の規範整備は域内最高水準**。ところが法的能力（3.3.1）と脱施設化（3.3.2）がゼロで、測定（3.2.1）も空白である。

**そして重要なのは、この評価が「法案成立前」の数字だということ。** 法案が現在の形で成立し、AP従事者に資格証を要求し、財源を許可センターからの調達に一本化するなら、**1.2.3は下がりうる。** OHCHRツールを事前・事後で使う意味がここにある。

## 5. ラテンアメリカ諸国との比較

RELAVINは同一のツールで域内6件を評価済み。モンゴルを同じ物差しに置くと：

| 対象 | 総合 | 1.2.3 人的支援 | 特徴 |
|---|---|---|---|
| **コロンビア**（CONPES 4198） | ~65–70% | 部分・高 | 法2297号でAPの法的プロフィールを規定、AP連動の現金給付。運用の空白を自ら診断 |
| **ペルー**（DS 001-2026-MIMP） | ~55–60% | 部分・高 | ケアシステム法がないままAPを法制化。域内で最良のAP定義。学校でのAP条項は国際的にも独自 |
| **ドミニカ共和国** | ~50–55% | 部分 | INFOTEPのAP養成カリキュラム（2023）＋FONADISの自立生活指定＝**養成と資金の器はあるがサービスが動いていない** |
| **メキシコ市**（CDMX法, 2026年7月） | ~50–55% | 部分（~40-45%） | 55条XでAPアクセスを**測る義務**、70条でAPをサービスとして列挙。CIL統合と個人予算は欠落 |
| **★モンゴル**（2016年法32条＋A/187） | **~40–45%** | **部分（~45-50%）＝最高** | **一次法＋施行規程＋AP基準＋法定財源2経路。しかし単価・時間数・実績が空白、本人は雇用主でない** |
| **チリ**（21.805号法, 2026年2月） | ~40–45% | 部分・低 | 「支援」を法律名に持つ唯一の国。**しかしAP言及ゼロ**、国家計画は入所定員を拡大 |
| **スクレ**（ボリビア, 493/2025号法） | ~15–20% | 欠落（~5-10%） | 障害サービスが救貧・リハビリ部局に丸投げ |

### 比較から出てくる4つの論点

**(1) 総合順位とAP順位が逆転している唯一の事例。** モンゴルは総合ではチリと並ぶ中位だが、**指標1.2.3だけを見ると域内最高**である。これは他のどの国にも起きていない。ラテンアメリカ側にとっても学ぶべき事例——**APの規範は、ケアシステム法を待たずに障害者権利法の下位規範だけで作れる**、という実証だからである。

**(2) ドミニカ共和国と鏡像をなす。** ドミニカはINFOTEPのAP養成カリキュラム（4モジュール）とFONADISの資金指定を持ちながらサービスが動いていない。モンゴルは規程・基準・2財源を持ちながら規模がない。**「器はあるが動かない」という同じ病理**であり、原因の突き止め方を共有できる。

**(3) 入口が逆で、出口が同じ。** ラテンアメリカは給付が薄く、ケアシステム論から入ってAPに到達しようとして、そのたびにAPが落ちる。モンゴルは給付が厚く、高齢者ケアの制度化から入って、やはりAPが脇に置かれる。**ケアの本流の枠組みは、放っておくとAPを含まないのではなく、含まない形で完成する。** OIT『Cuidando desde el territorio』（2025）にAP言及がゼロだったのと同型である。

**(4) 「先にAPを法制化した国」に共通する次の壁は単価と時間数である。** ペルーもモンゴルも、定義と権利までは到達した。そこから先に必要なのは、**支給決定の手続・時間数の基準・単価表**という行政の数字であり、これは条文の議論ではなく予算の議論になる。ペルーとモンゴルは同じ壁の前に立っている。

## 6. 介助制度の実装に向けて取るべき対策

### 6.1 戦略の芯 — 「制度を作る」ではなく「ある制度を守り、動かす数字を入れる」

政策目標を「介助制度の創設」に置くと、相手は「それは介護サービス法でやる」と答える。そうではなく——

> **モンゴルには既に、自立生活の権利とパーソナルアシスタンスを定めた法律（2016年法32条）と、その施行規程・AP基準・2つの法定財源（大臣命令A/187、2022年施行）がある。欠けているのは支給時間数・単価・受給手続という運用の数字であり、実績データである。新たな介護サービス法は、この既存の枠組みを引き継ぐのか、上書きするのかを明らかにしなければならない。**

この立て方の利点は3つ。①新規立法要求ではなく既存規範の実施であるため政治的抵抗が小さい ②成果が明確に測定可能（単価表・時間数基準・利用者数の公表） ③CRPD委員会2023年勧告の実施という国際的な後ろ盾がつく。

### 6.2 介護サービス法案に対する4つの最小限修正案

今秋の国会会期（10月〜）で法案が動く前提で、**条文レベルの提案を用意する**。全部が通らなくても、提案があること自体が政策対話の入口になる。

| # | 条文 | 提案 |
|---|---|---|
| **1** | **2条または3条（適用範囲）に相互参照** | 「障害者の自立生活支援については**障害者権利法32条および同条に基づき定められた規程による**」旨を挿入。**最優先。これ一本でAPの吸収を防げる** |
| 2 | **31.1に第4号を追加** | 「**要介護者が自ら選任し、その指示のもとに支援を行う者**」を人的資源の類型として追加 |
| 3 | **32条に例外規定** | 上記類型については、A/187のAP基準（研修受講・経験・健康診断）をもって足りるものとし、資格証を要しない |
| 4 | **37.1に新号／38条に並列** | 財源の源泉に「**要介護者本人に直接配分され、本人の管理のもとで支出される財源**」を追加。国の調達（38.1）と並ぶ第二経路として明記。既存の社会福祉基金・雇用支援基金からのAP財源をここに接続する |

補助的に：**10.1.1の選択権を「提供機関の選択」から「支援の内容・時間帯・担い手の決定」へ拡張**／**18条の分類手続に本人の意思と選好を反映させる規定**／**協議機関に障害当事者団体の議席を置く条項**（32.6の水準を新法にも及ぼす）。

### 6.3 A/187を引き上げる — 本命の作業

法案対応と並行して、既存規程の改訂を目指す。A/187は既に一度「改訂承認」されており、**改訂の前例がある**。

1. **支給決定手続と時間数の基準を定める**（現在は空白）
2. **単価表を定め、公表する**（現在は空白）。社会福祉基金・雇用支援基金からの支出根拠として不可欠
3. **本人が介助者を選任・指示する回路**を明記する。第一段階として「利用者が指名した者を提供機関が雇用する」方式（日本のCILが制度化の初期に採った形）は現行の枠組みを壊さずに実装できる
4. **1介助者が複数利用者を担当する運用の見直し**（個別的関係はOHCHRツールの明示基準）
5. **家族介助の取扱いを明確化する**
6. **利用実績の公表義務**を置く

### 6.4 データを作る — 現行事業の成果がそのまま政策資料になる

**モンゴルには、A/187に基づくAPを全国で何人が利用しているかの公表統計が見当たらない。** 法案35条が登録するのは提供機関と労働者だけで、本人の支援アクセスを測る指標がない（メキシコ市法55条Xが「APへのアクセス」を測定義務にしたのと対照的）。

Universal Progress自立生活センター（会員140名超、職員17名中12名が障害当事者）が蓄積している介助派遣の実績——利用者数、時間数、時間帯分布、単価、利用者の生活の変化——は、**この国で唯一の、実務に裏づけられたAPデータになりうる**。これを労働社会保障省に持ち込めることが、単価表と時間数基準の議論を始める最短経路である。

### 6.5 UPセンターを制度内に位置づける — ただし本人主体を手放さない

A/187はUPセンターが認定提供機関になる道を既に開いている（32.4、32.5、認定手続）。法案13条の許可・38条の調達も同様である。**制度外に留まる限り、指標も予算も動かない。** OHCHRツールは「CILと介助者協同組合が制度ネットワークに統合されていること」を明示的な評価基準としている。

ただし条件がある。**入り方を間違えると、CILが「介助者を雇用して派遣する介護事業所」になり、本人が雇用主である関係が消える。** これは日本のCILが制度化の過程で直面したのとまったく同じ論点であり、その経験は国際的に見ても稀少な資産である。「制度に入りながら当事者主体を保つ方法」を語れる主体は多くない。

## 7. 未確認事項

本メモの精度を上げるために確認が必要な点：

1. **国会提出版（10章30条）の正文**。条文番号の振り直しが必要
2. **A/187に基づくAPの実施状況** — 認定を受けた提供機関は何団体あるか。社会福祉基金・雇用支援基金から実際に支出されているか。利用者は何人か。**規範と実態の距離を測る鍵**
3. **A/187が2023年の法改正（2023年7月7日、12月8日）の影響を受けたか**
4. **UPセンターが法案プロセス（労働社会保障省ライン）にアクセスできているか**。障害者副委員会とは別ルートの可能性が高い
