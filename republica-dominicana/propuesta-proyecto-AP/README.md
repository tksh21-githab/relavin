Recorrido: **CIMUDIS → CONADIS → banca de desarrollo (presentación oficial del CONADIS).**

Por eso el texto **no lleva nombres de personas ni apreciaciones internas** (relaciones, quién está dentro de qué círculo, qué puede o no puede hacer cada agencia). Al preparar versiones nuevas, mantener ese criterio.
